# Three-phase issue review

Historical local milestone. The counts and publication boundaries below describe
that earlier working tree, not the current release. See [Release Roadmap](RELEASE-ROADMAP.md)
for the current retain/defer decisions and separate core/research validation.

This pass prioritizes trustworthy evidence before new capabilities. Everything below is local, offline work using synthetic fixtures or already-retained public-project evidence. It does not update Dazzler or its installed skill.

## Phase 1: Trust the inputs

Priority order: **#8, #9, #10, #11**, with regression coverage for the already-committed **#12 and #13** corrections.

- **#8:** decision fingerprints sort Unicode scalar keys identically in JavaScript and Python. Invalid abstention types and lone surrogates are rejected. Decision contract version is now 0.2.1; regenerate fingerprints when migrating.
- **#9:** knowledge drift separates exact bytes, CRLF-only differences, substantive differences and missing files. Raw provenance hashes remain authoritative. Unsupported historical public-drift counts are withdrawn; a separate public-tree check identifies seven paths absent from the specific checked revision, not from all history.
- **#10:** CI explicitly provisions Python 3.10 and a latest-Python canary beside Node 22. Local tests do not establish that either new CI lane has passed.
- **#11:** retrospective request/response hashes preserve capture provenance without inventing missing timestamps. Permission is recorded as customer-confirmed, not independently verified legal clearance. No new provider calls were made.
- **#12/#13:** committed-source distribution allowlists and immutable model-identity gates remain in place. Moving aliases cannot qualify release evidence; model agreement is not aesthetic validation.

Improvement: cross-runtime decisions and release inputs are easier to reproduce, and unknown provenance cannot quietly become positive evidence.

## Phase 2: Make the foundation usable

Priority order: **#14, then #15**.

- **#14:** a versioned consumer contract exposes capabilities and validates extracted artifacts against a caller-trusted manifest. Missing, tampered or unsupported artifacts preserve the previous pin and native checks. Packaging tests import both runtimes from a generated archive, not the checkout.
- **#15:** optional retrieval applies hard medium, palette, font and interaction requirements before contextual heuristics. Missing capabilities remain unknown; incompatible requests can return no-fit. Detail records are loaded separately and hash-checked. Diversity breaks equal-score ties; agreement never overrides requirements.
- A local index was generated from the unchanged 1,000 retained winners. This does not add judgments, recover losers, or establish that the recipes are beautiful.

Improvement: consumers can negotiate support explicitly and use recipes as constrained starting points instead of unquestioned recommendations.

Remaining: retrieval is experimental. Its evaluation uses a synthetic lexical proxy, not the complete Dazzler retrieval stack or a real agent workflow. The new instruments and retrieval modules are deliberately outside the reviewed release profile.

## Phase 3: Measure bounded outcomes

Priority order: **#16, #17, #18**.

- **#16:** HTML instruments check declared font loading, scroll containment, focus targeting, simple focus outlines and center-point obstruction. Evidence binds exact artifact, plan, renderer, viewport, theme and state. Unsettled or unsupported observations remain unknown.
- **#17:** a native DOCX adapter checks bounded OOXML package facts against exact bytes. Synthetic editable documents cover title, heading, font, table and page-geometry failures. Pagination remains unknown; no Word or LibreOffice rendering was performed.
- **#18:** the offline comparison records all cases, source hashes, separate development/held-out IDs, equal candidate limits, failures, unknowns, category diversity, latency and zero provider cost. It rejects automatic overall ranking rather than turning separate outcomes into a beauty score.

In ten synthetic held-out briefs, the lexical proxy violated font availability in five briefs; constrained retrieval violated it in zero and returned five no-fits. Across 20 desktop/mobile renders, instruments detected all 12 injected defects with zero false alarms in these fixtures; 12 unsupported measurements remained unknown. Seven DOCX packages were inspected, not rendered. See [the reproducible report](downstream/results.json) and [protocol](downstream/PROTOCOL.md).

Improvement: failures and unsupported measurements become inspectable evidence instead of silent passes.

Remaining: these are bounded engineering fixtures, not human preference evidence, a causal study, or proof of production Dazzler gains. Full host/agent ablations, broader held-out coverage, native rendered pagination and human assessment remain open. Do not close #15, #17 or #18 on the strength of this milestone alone.
