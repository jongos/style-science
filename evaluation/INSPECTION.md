# Measure a fact, not a feeling

Experimental inspection schema 1 binds exact artifact SHA-256, plan, viewport,
theme, interaction state and renderer version. JavaScript and Python verify the
same evidence. Missing, stale, unsupported and unsettled observations are unknown.
Existing relation research is preserved; these instruments do not duplicate its
DOM-parent/ordering and signed rectangle tests.

| Instrument | What it measures | What it does not certify |
| --- | --- | --- |
| Font face loaded | An inspectable declared FontFace loaded and is the primary CSS family | Actual per-glyph face, font licensing or system fallback |
| Scroll containment | Integer scroll dimensions fit the target's client dimensions | All paint clipping, line readability or ancestor clipping |
| Focus target | Exact active target and enabled control state | Complete keyboard order or accessibility |
| Focus outline | Focused target has a simple nontransparent CSS outline | Perceptual visibility; shadow indicators remain unknown |
| Center hit | The target receives hit testing at its center | Full-area occlusion or hierarchy |

The host supplies an already-rendered page and truthful artifact/state binding.
The collector does not navigate or operate controls. Font settling is bounded,
followed by two 50ms geometry observations; active animations invalidate settling.
This sampling does not guarantee future stability. Transforms and opacity effects
are conservative unknowns. The tests cover normal, missing-font, long/localized,
overlay, hidden-focus, expanded/error/loading, animated and shadow-focus cases at
390 and 1280 pixels. Screenshots are review evidence, not aesthetic scores.

## Native documents

`docx_adapter.py` reads bounded UTF-8 OOXML packages without rewriting them. It
reports title/heading style facts, explicit font declarations versus host-supplied
availability, one-section page geometry and explicit absolute table widths.
Custom inherited styles, automatic/percentage table layout and native pagination
remain unknown. Every observation binds the exact DOCX bytes. JS/Python consumers
verify portable JSON, not an HTML approximation of Word.

Seven original fixtures include headings, quotations, callouts, tables, page
breaks, long content and deliberate title/font/geometry defects. Their editable
bytes are retained in the local evidence directory. No native rendering has been
performed. LibreOffice output would bind its own version and fonts and cannot
certify Microsoft Word pagination; neither renderer is installed automatically.
Native rendered bounds, font weight availability and visual review remain open
work under #17. Dazzler's document and slide delivery gates are unchanged.
