# Changelog

## 2026-10-07 — Manifesto and Landing Page

- **Added:** Original eight-part AI design manifesto, responsive Dazzler-designed landing page, keyboard-operated spacing study, local licensed variable font, text edition and GitHub Pages workflow.
- **Why:** State the project's design commitments while distinguishing engineering checks from unproven aesthetic claims.
- **Validation:** Four viewport sizes, overflow and font checks, keyboard interaction, automated accessibility checks, heading audit and visual inspection. These verify delivery behavior, not human preference. Browser evidence is summarized in `site/VALIDATION.md`.

## 0.1.0 — 2026-10-07 — Initial local prototype

- **Added:** Independent JavaScript and Python verification engines, a host-supplied browser adapter, machine-readable plan schema, scoped knowledge registry, preserved Dazzler reference dataset, and a preregistration design.
- **Changed:** The proposal is narrowed to executable knowledge and measured constraints. Medium representations remain native. Generation stays with the consuming agent.
- **Why:** Test whether explicit knowledge adds value beyond a compute-matched generation/review loop. Keep the portable core independent of Dazzler.
- **Validation:** Shared fixtures exercise numerical checks, missing/stale observations, invalid input and cross-language agreement. Browser checks exercise actual rendered DOM. These are implementation tests, not evidence of aesthetic improvement.
