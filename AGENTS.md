# Maintaining Style Science

This repository owns the independent Generative Design Canvas (GDC). Dazzler consumes a versioned copy; do not make Dazzler the runtime authority or add imports from its installed skill.

Implement interoperable JavaScript and Python consumers. Keep the verification core dependency-free. Renderer adapters are separate. HTML means a rendered target, including framework output, not the core implementation language.

Preserve native medium semantics. Do not claim a universal design theory, a learned generator, aesthetic quality gains or human-validated diversity from conformance tests. Unknown is never pass. Explicit task constraints cannot be waived by a style score.

Knowledge imports retain provenance and licenses. Mixed guidance remains uncurated until individual claims have scope, evidence and tests. Heuristics may inform agent judgment but cannot silently become hard requirements.

Run `node --test test.mjs` with Python available. Run `node --test browser.test.mjs` when changing the HTML adapter, with host-provided Playwright. Verify downstream vendored hashes. Human studies require completed preregistration before collection; fixtures are not experimental results.

Publish only when the user authorizes it. Keep source, test evidence and changelog together. Never add private briefs, client artifacts or judge identities to the repository.
