## Make a reversible CSS refinement

**Goal:** Refine this CSS file and keep a precise way to revert only this change.

**When to use:** When you have an existing interface or a concrete design brief.

**Prompt:** Use $dazzler-frontend to refine this CSS file and keep a precise way to revert only this change.

**Exercises:** Check the supplied evidence, choose a suitable visual direction, implement within the authorized scope, and inspect the result.

**Expect:** A bounded single-file plan, validated application and a reversible change record.

**Tips:** Reject intervening edits; use Git for coordinated multi-file changes.

**More control:** Optional: specify audience, required brand values, target format and constraints. Leave visual choices to Dazzler unless you want control.

Agent route: `scripts/project.py plan`. Read the linked workflow for arguments and schemas; this is not a command to paste.

Workflow: [design studio](design-studio.md).
