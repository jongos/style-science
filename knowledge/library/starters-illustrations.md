## Make an interactive visual guide

**Goal:** Turn this image or SVG into an accessible interactive explainer.

**When to use:** When you have authorized artwork and useful region descriptions.

**Prompt:** Use $dazzler-frontend to turn this image or SVG into an accessible interactive explainer.

**Exercises:** Check the supplied evidence, choose a suitable visual direction, implement within the authorized scope, and inspect the result.

**Expect:** Named hotspots, keyboard controls, descriptions and a text equivalent.

**Tips:** Use supplied or authorized artwork; verify region coordinates and the target framework.

**More control:** Optional: specify audience, required brand values, target format and constraints. Leave visual choices to Dazzler unless you want control.

Agent route: `scripts/hotspots.mjs`. Read the linked workflow for arguments and schemas; this is not a command to paste.

Workflow: [interactive illustrations](interactive-illustrations.md).
